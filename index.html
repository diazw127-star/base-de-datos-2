Guía de Configuración de Reglas Firestore

Instrucciones para activar el modo tiempo real sin restricciones de permisos.

Si la aplicación muestra 🔴 Error de Permisos, pega estas reglas en tu consola de Firebase para habilitar sincronización en tiempo real entre múltiples pantallas:

  1. Ingresa a la Consola de Firebase.
  2. Selecciona tu proyecto: materiaprima-7df61.
  3. Ve a Firestore Database → Pestaña Reglas (Rules).
  4. Copia e introduce las siguientes reglas:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
